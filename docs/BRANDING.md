# Zyrex identity

Name: Zyrex. Ticker: ZYRX. Unit: nanoZYRX (10^-9 ZYRX).

The native SVG mark is in `branding/zyrex-mark.svg`: a cut Z with a mint body
and coral corner on a graphite square. It scales without raster dependencies.

Palette: graphite `#111923`, background `#0c121a`, mint `#71f5be`, coral `#ff7768`,
text `#e8edf3`. Typography: system sans for UI, monospace for identifiers.

The node panel and OpenAPI title use Zyrex. Internal SDK package names and
protocol JSON schema names preserve transaction compatibility. Third-party
license notices remain applicable.
